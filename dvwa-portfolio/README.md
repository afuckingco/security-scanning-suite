# DVWA Portfolio

Dokumentasi hands-on terhadap **Damn Vulnerable Web Application (DVWA)** — lingkungan
*authorized* untuk belajar dan mendemonstrasikan teknik pengujian keamanan web.

## Isi

| Folder | Topik |
|---|---|
| [01-setup](01-setup/) | Instalasi & konfigurasi DVWA (Docker/swamp) |
| [02-reconnaissance](02-reconnaissance/) | Eksplorasi, enumerasi, fingerprinting |
| [03-sql-injection](03-sql-injection/) | Demonstrasi SQL injection & mitigasi |
| [04-analysis](04-analysis/) | Analisis temuan & rekomendasi perbaikan |
| [05-resources](05-resources/) | Referensi lanjutan |

## Etika

Hanya untuk lingkungan lab/authorized. Jangan digunakan pada sistem tanpa izin.
